## 1. Вступ (Introduction)

LocalSquash — безкоштовний веб-сервіс для стиснення та конвертації відео, зображень і аудіо, що виконує всю обробку локально у браузері користувача за допомогою FFmpeg, скомпільованого у WebAssembly. Проблема, яку вирішує продукт: наявні онлайн-компресори вимагають завантаження файлів на сторонні сервери (ризики приватності, затримки, ліміти розміру, водяні знаки), а десктопні рішення — встановлення програмного забезпечення. Цільова аудиторія — креатори контенту, розробники та команди, що готують медіафайли для email, месенджерів, соціальних мереж і веб-публікації.

## 2. Загальний опис (Overall Description)

**Функціональні блоки:**

- Відеокомпресор: кодування H.264/MP4 із керуванням CRF, швидкісним пресетом, масштабом роздільної здатності, бітрейтом аудіо; трим і кроп.
- Компресор зображень: вихідні формати WebP/JPEG/PNG, якість 1–100, кадрування, видалення метаданих.
- Аудіокомпресор: кодеки AAC/MP3/Opus, бітрейти 32–320 kbps, обрізання за часом.
- Інформаційний блок: блог із довідковими матеріалами щодо стиснення.

**Актори:**

- **Користувач (анонімний)** — повний доступ до всіх функцій без реєстрації; єдина роль у системі.
- **Розробник / адміністратор** — оновлення застосунку та контенту блогу; діє поза інтерфейсом системи.

**Зовнішні залежності:** FFmpeg.wasm; браузерні API (WebAssembly, File API, Web Workers, Cache API); CDN; Google Tag Manager (вебаналітика); Buy Me a Coffee (донати).

## 5. Обмеження (Constraints)

- **C-01:** Обробка виконується виключно client-side; серверні обчислення відсутні (принципове архітектурне рішення продукту).
- **C-02:** Кодування реалізується через FFmpeg, скомпільований у WebAssembly.
- **C-03:** Максимальний розмір файлу обмежений доступною оперативною пам'яттю пристрою (практична межа ~2 ГБ).
- **C-04:** Вихідний відеоформат — лише H.264 MP4 (заради максимальної сумісності); H.265/AV1 не підтримуються.
- **C-05:** Потрібен браузер із підтримкою WebAssembly (Chrome, Firefox, Safari, Edge актуальних версій).
- **C-06:** Розповсюдження збірки FFmpeg регулюється ліцензіями LGPL/GPL.

## 6. Глосарій (Glossary)

- **FFmpeg.wasm** — мультимедійний фреймворк FFmpeg, скомпільований у WebAssembly для виконання у браузері.
- **WebAssembly (WASM)** — бінарний формат виконання коду у браузері з близькою до нативної швидкістю.
- **CRF (Constant Rate Factor)** — параметр якості кодування H.264; діапазон 0–51, менше значення — вища якість і більший файл.
- **H.264 / AVC** — найпоширеніший відеокодек із універсальною підтримкою на пристроях.
- **WebP** — формат зображень Google із на 30–50% кращим стисненням за JPEG при еквівалентній якості.
- **AAC** — аудіокодек, наступник MP3 із кращою якістю при тому ж бітрейті.
- **Client-side** — виконання обчислень на пристрої користувача, без участі сервера.
- **Trim / Crop** — обрізання медіа за часом / кадрування зображення у просторі.
- **MoSCoW** — метод пріоритизації вимог: Must / Should / Could / Won't have.
